# Update project Markdown

1. Review the changes for the task and check every project `*.md` file from the repository root, including files in nested and hidden directories.
2. Update each file whose content is affected. Check setup and configuration when dependencies or runtime settings change. For changes to the API contract, proxy, or cross-origin requests, verify the frontend and backend documentation together. Keep `COMMANDS.md` in sync when project commands are added or changed.
3. Verify edited commands, paths, environment variable names, API examples, diagrams, and links against the project. Preserve existing text that still applies.
