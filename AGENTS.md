# Project instructions

When you share a new command for working with this project, add it to `COMMANDS.md` in the same turn. Explain what it does and include the working directory and prerequisites when needed. Update existing entries as workflows change and keep credentials out of examples.

Whenever you change project code, dependencies, or runtime configuration, read and apply [update-readmes](.agents/skills/update-readmes/SKILL.md) before finishing. Check all project Markdown files against the change and update each affected file in the same change.

When a change affects architecture or a workflow shown in the project documentation, read and apply [update-architecture](.agents/skills/update-architecture/SKILL.md) before finishing. This includes renaming LangGraph nodes.
